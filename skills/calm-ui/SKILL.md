# calm-ui

## 準備（MANDATORY PREPARATION）

ui-design-grounding スキルを呼び出し、以下のリファレンスを読み込む:

- `ui-design-grounding/reference/typography.md`
- `ui-design-grounding/reference/color-system.md`
- `ui-design-grounding/reference/spatial-layout.md`
- `ui-design-grounding/reference/motion-design.md`
- `ui-design-grounding/reference/anti-patterns.md`

## 手順

### 1. 過剰さを多軸で診断

| 軸 | 過剰度（1-5） | 具体的な問題 |
|----|-------------|-------------|
| 色の過剰 | ? | 彩度過高、アクセント色多数、グラデーション乱用 |
| 装飾の過剰 | ? | シャドウ、ボーダー、背景パターン、アイコン過多 |
| タイポグラフィの過剰 | ? | フォント種類多数、ウェイト・サイズバリエーション過多 |
| モーションの過剰 | ? | アニメーション過多、不要なトランジション |
| レイアウトの過剰 | ? | カードネスト、密集、要素過多 |

### 2. 削減の方向性を決定

- **何を残し、何を削るか**を明確にする
- 核となる1-2の要素を特定し、それ以外を控えめにする
- 60-30-10ルールの再適用を検討

### 3. 具体的な変更を実施

**色**:
- アクセント色を1-2色に絞る
- 彩度を下げる（OKLCHで chroma を調整）
- ニュートラルの面積を増やす（60%以上）
- 不要なグラデーションの除去

**装飾**:
- 不要なシャドウ・ボーダー・背景パターンの削除
- アイコンの間引き（テキストで十分な箇所）
- 装飾的な視覚要素の除去

**タイポグラフィ**:
- フォントを1-2ファミリーに絞る
- サイズ段階を5段階に整理
- ウェイトを2-3種類に制限

**モーション**:
- 装飾的アニメーションの削除
- 機能的なトランジションのみ維持
- デュレーションの短縮

**レイアウト**:
- カードのフラット化（ネスト解消）
- 余白のリズム整理（密集と開放の対比）
- 不要な区切り線・セパレーターの除去

### 4. バランス検証

- **控えめ ≠ 退屈**: 視覚階層と個性は維持する
- スクイントテスト: 主要素が識別できるか
- 情報の優先順位が伝わっているか
